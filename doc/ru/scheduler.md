# Scheduler
Это параметр конфигурации, который включает запуск другого ПО через `action` или вызов функций из другого ПО через контекст `lang`.\
Он позволяет повторно запускать функцию через равные интервалы времени, заданные ключом `period`.\
Директиву можно указать несколько раз. Один scheduler может управлять только одним action или lang.

## Обзор конфигурации
```
scheduler {
  name <name>;
  period <1h15s>;
  datasource <internal>;
  action <run-script>;
  lang <call-func>;
  expr <filter promql>;
}
```

## name
Задаёт только имя контекста.\
Это ключ, по которому API Alligator обновляет поля контекста scheduler.\
Когда scheduler запускает `action`, это имя также добавляется как префикс к oneshot-ключу aggregator (`scheduler:<name>:…`). Так несколько scheduler могут одновременно вызывать **один и тот же** action без коллизий. Повторный тик **того же** scheduler по-прежнему использует тот же ключ, поэтому action не будет запущен дважды параллельно.

## action
Указывает имя action для выполнения.\
Несколько scheduler могут ссылаться на одно и то же имя action. Используйте различный `expr` на каждом scheduler, чтобы экспортировать разные подмножества метрик.


## lang
Указывает имя языка для выполнения.


## expr
Задаёт PromQL-выражение для фильтрации метрик, которые будут переданы вызываемому `lang` или ПО в `action` на stdin.

Голый идентификатор — это **точное** имя метрики (не префикс). `expr x509_cert_expire_days;` экспортирует только это семейство, а не соседние, например `x509_cert_not_after`.

Чтобы сопоставить несколько имён, используйте PromQL `__name__=~` / `__name__!~` (PCRE, без якоря). `name` принимается как псевдоним `__name__`. Некорректное регулярное выражение не совпадёт ни с чем.

```
expr '{__name__=~"^x509_cert_"}';
expr '{__name__!~"^cpu_"}';
expr 'count({__name__=~"^socket_stat"})';
```

Метки `=~` / `!~` для ключей, отличных от `__name__`, игнорируются. `x509_cert_.*` как голый идентификатор — это буквальное имя, а не regex.


## period
Задаёт интервал времени для повторного выполнения команды.\
Подробнее о единицах, которые можно указать в конфигурации, см. в [документации](https://github.com/alligatormon/alligator/blob/master/doc/configuration.md).


## datasource
Указывает источник данных для query.\
Для локальных запросов метрик используйте ключ `internal`.\
Сейчас поддерживается только вариант `internal`.
